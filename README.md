
# Supply Chain & Inventory Management Dashboard

## Overview

This project focuses on analysing supply chain and inventory performance through an interactive Power BI dashboard.

Using a supply chain dataset, the dashboard transforms operational data into visual insights, helping explore inventory levels, transportation costs, order accuracy and other key performance indicators (KPIs).

The objective is to demonstrate how data visualisation and business intelligence tools can support operational monitoring and more informed supply chain decision-making.

## Project Objectives

- Analyse inventory levels and supply chain performance.
- Monitor key operational KPIs.
- Explore transportation costs and inventory-related metrics.
- Identify patterns and potential inefficiencies in supply chain operations.
- Transform raw data into clear and interactive visual insights.

## Dataset

The dataset includes several supply chain and inventory-related variables, such as:

- Inventory Level
- Transportation Cost
- Order Accuracy
- Lead Time
- Backorder Status
- Cost of Goods Sold
- Average Inventory
- Warehouse and other operational information

## Dashboard & Key Metrics

The Power BI dashboard explores different aspects of supply chain performance, including:

- **Inventory Management:** Monitoring inventory levels and average inventory.
- **Transportation Costs:** Analysing transportation-related expenses.
- **Order Accuracy:** Monitoring order fulfilment accuracy.
- **Lead Time:** Exploring delivery and replenishment timelines.
- **Backorders:** Analysing the occurrence of backorders.
- **Cost of Goods Sold:** Exploring operational and inventory-related costs.

## Tools & Technologies

## Methodology

1. Imported and explored the supply chain dataset.
2. Cleaned and transformed data using Power Query.
3. Adjusted data types and prepared variables for analysis.
4. Created visualisations and KPI cards in Power BI.
5. Designed an interactive dashboard to present supply chain performance indicators.

## Business Applications

Supply chain analytics can help organisations:

- Monitor inventory performance.
- Improve visibility across supply chain operations.
- Identify potential inventory and logistics inefficiencies.
- Support cost monitoring and operational planning.
- Make more informed, data-driven decisions.
